# Bill Split 💸

Fair restaurant bill splitting app with OCR receipt scanning.

## ✨ Features
- 📸 Upload receipt images (JPEG, PNG, WebP)
- 🧠 AI OCR extraction using Google Vision API
- ✅ Smart item selection per person
- 🧮 Automatic settlement calculation
- 💳 Razorpay payment integration

## 🛠️ Tech Stack
- **Frontend:** Next.js 15, TypeScript, TailwindCSS, Shadcn/ui
- **Backend:** Next.js API Routes
- **OCR:** Google Cloud Vision API
- **Payments:** Razorpay
- **Database:** Supabase (planned)

## 🚀 Try It Locally

```bash
git clone https://github.com/musthaqahmedg/bill-split.git
cd bill-split
npm install
npm run dev
```

Then open: http://localhost:3000
